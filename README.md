This repository contains replication code for the analysis of sufficient and reliable electricity at healthcare facilities in the Democratic Republic of Congo. Due to data-sharing agreements, several raw datasets used in the analysis are restricted and are not included in this repository. All data processing and analysis steps are fully documented and reproducible for users with appropriate data access.

The repository is organized into three main directories: code/, data/, and output/.

The code/ directory contains all scripts required to clean data, construct analytical variables, and reproduce tables and figures. The scripts should be run in numerical order. 01_surveycleaning.do cleans the restricted facility survey data and constructs facility-level electricity access, reliability, and installation timing variables. 02_sniscleaning_surveymerge reads in raw SNIS (DHIS2) health facility data, cleans and aggregates outcomes, and merges these data with the cleaned survey data to produce the main analytical dataset. 03_spatialvars_processing processes publicly available spatial covariates (wealth, population density, distance to infrastructure) and outputs facility- or health-zone–level spatial measures. 04_analysis contains all statistical analysis code, including TMLE, OLS, IPW, and fixed-effects models, as well as all figures and tables reported in the paper.

The data/ directory is structured to mirror the inputs expected by the code. The data/survey/ folder should contain the raw restricted facility survey files used to measure electricity access, reliability, and infrastructure characteristics. The data/snis/ folder should contain the raw restricted SNIS (DHIS2) Excel files used to construct health outcomes and service delivery measures; these files are cleaned directly from raw format using the provided code. The data/sensor/ folder should contain restricted high-frequency power quality and reliability sensor data used in the within-facility and TWFE analyses. The data/spatial/ folder contains a Readme file with detailed information on how to download publicly available spatial datasets that are used in the analysis, which are too large to store on GitHub.

Restricted data files are not included in the repository. The code checks for the presence of required restricted datasets and will halt gracefully with informative messages if they are not found. Users with appropriate permissions should place the required files in the corresponding data/ subdirectories using the filenames expected by the scripts.

The output/ directory stores intermediate and final outputs generated by the code. This includes cleaned datasets saved as RDS files, temporary processing outputs stored in output/temp/, summary tables, and figures used in the manuscript and supplementary materials. Output files can be safely deleted and regenerated by rerunning the scripts.

All scripts are designed to be run from the repository root using relative paths. The analysis relies on R and Stata; required R packages are loaded within the scripts. The workflow is fully reproducible conditional on access to the restricted datasets described above.

*Data Availability Statement*

This study uses a combination of restricted administrative health data, restricted facility survey data, restricted electricity sensor data, and publicly available spatial datasets.

Raw SNIS (DHIS2) health facility data, facility survey data, and electricity sensor data are subject to data-sharing agreements with implementing partners and government authorities and therefore cannot be made publicly available. Access to these data may be granted by the original data providers subject to approval and applicable agreements.

All data cleaning, variable construction, merging, and analysis code used in the study is publicly available in this repository. The replication scripts are designed to run from raw restricted inputs and include explicit checks that halt execution when restricted data are not present. Users with appropriate data access can reproduce all analytical datasets, tables, and figures reported in the paper.

Publicly available spatial covariates can be regenerated using the provided processing scripts in combination with the download instructions provided in the Readme file in the spatial data folder.
